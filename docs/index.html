ConvMamSPN + UGGP-ST

Mamba-based Spacecraft 6D Pose Estimation with Uncertainty-Guided Geometric Pseudo-label Self-Training

Zeng Xin et al.

Paper Code (GitHub) Dataset Model BibTeX

Abstract

ConvMamSPN predicts spacecraft keypoint heatmaps using a ConvNeXt backbone and Mamba-based hierarchical decoder, then solves 6D pose with geometric PnP. UGGP-ST improves synthetic-to-real adaptation by uncertainty-guided pseudo-label filtering and teacher-student self-training on SPEED+ Lightbox and Sunlamp.
