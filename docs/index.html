ConvMamSPN + UGGP-ST

Mamba-based Spacecraft 6D Pose Estimation with Uncertainty-Guided Geometric Pseudo-label Self-Training

Zeng Xin et al.

Paper Code (GitHub) Dataset Model BibTeX

Abstract

ConvMamSPN predicts spacecraft keypoint heatmaps using a ConvNeXt encoder and Mamba-based hierarchical decoder, then recovers 6D pose with geometric PnP. UGGP-ST improves synthetic-to-real transfer by uncertainty-guided pseudo-label filtering and teacher-student self-training, targeting SPEED+ Lightbox and Sunlamp.

Method Overview

ConvMamSPN

  • ConvNeXt backbone
  • CrossScanMamba
  • MambaResBlock
  • Hierarchical decoding
  • Keypoint heatmap prediction
  • EPnP/RANSAC PnP pose recovery

UGGP-ST

  • Heatmap peak confidence
  • Entropy/local-variance uncertainty
  • PnP reprojection consistency
  • Pseudo-label filtering
  • Teacher-student self-training
